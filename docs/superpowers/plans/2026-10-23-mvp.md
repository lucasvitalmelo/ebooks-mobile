# MVP do E-books — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Importar `.epub` pelo seletor do sistema, mostrar a biblioteca com capas, ler o livro numa WebView com epub.js, salvar o progresso e ajustar a aparência (tema, fonte, tamanho, entrelinha, margem).

**Architecture:** O app RN cuida de arquivos (`expo-file-system`), banco (`expo-sqlite` atrás de uma interface `Db`) e telas (Expo Router). O livro é renderizado por um app web mínimo (`reader-web/`, epub.js) compilado num único HTML embutido no app; RN e WebView conversam só pelo protocolo tipado de `src/reader/protocol.ts`, com mensagens grandes (o livro em base64) quebradas em pedaços. O ID do livro é o mesmo algoritmo do leitor web, para a sync da fatia 3 casar os mesmos livros.

**Tech Stack:** Expo SDK 58 (RN 0.88, React 19.3), TypeScript, Expo Router, expo-sqlite, expo-file-system (API `File`/`Directory`/`Paths`), expo-document-picker, react-native-webview, Zustand, JSZip, fast-xml-parser, epub.js 0.3.93, Vite + vite-plugin-singlefile, @fontsource, Jest (jest-expo) com `node:sqlite` nos testes.

**Spec:** `docs/superpowers/specs/2026-10-22-mvp-design.md` (atualizado no PR 0 deste plano).

## PR 0 — `docs/plano-mvp`

### Task 0: Ajustar o spec às decisões do plano

**Files:** Modify `docs/superpowers/specs/2026-10-22-mvp-design.md`

- [ ] **Step 1: Editar o spec** com estas mudanças (texto curto em cada seção correspondente):
  - **Dados → `books.id`**: não é o SHA-256 do arquivo inteiro, e sim o algoritmo do leitor web (`bookIdFor`): SHA-256 da lista "caminho, CRC-32 e tamanho" de cada entrada do zip, exceto pastas, `mimetype` e `.css`, lida do diretório central. Motivo: o leitor web reescreve as folhas de estilo ao importar, então o hash do arquivo mudaria entre web e celular; com o mesmo algoritmo, o mesmo livro tem o mesmo ID nos dois, o que a sync com o Drive (fatia 3) precisa.
  - **Dados → `books`**: `filePath` e `coverPath` são relativos ao `documentDirectory` (`books/<id>.epub`, `covers/<id>.<ext>`) — o caminho absoluto pode mudar entre versões do app no iOS. A capa guarda a extensão real da imagem. Nova coluna `locations TEXT` (as "locations" do epub.js, geradas uma vez por livro para calcular a porcentagem).
  - **Protocolo**: `open { base64, cfi, locations }`; eventos novos `locations { data }` (o leitor gerou as locations; o app guarda) e `centerTap` (toque no centro, que mostra/esconde a barra — a WebView engole os toques, então o aviso tem que vir da página). Mensagens maiores que 512 KB vão em pedaços (`{ id, index, total, data }`) remontados do outro lado.
  - **Bundle do leitor**: gerado no `postinstall` (roda no `npm ci` do CI e no `npm install` do EAS), em vez do hook `eas-build-post-install` e dos `pre*` scripts.
  - **Aparência**: mudar qualquer ajuste com um tema pronto ativo cria uma cópia "<nome> (meu)", que passa a ser o tema ativo; as mudanças seguintes editam a cópia. Temas próprios se apagam com toque longo. A folha é um `Modal` do RN (sem lib de bottom sheet).
  - **Testes**: repositórios testados com `node:sqlite` (embutido no Node 24, sem dependência nativa), não `better-sqlite3`.

```ts
import { DatabaseSync } from 'node:sqlite'
import type { Db, SqlValue } from '../db'

export function openTestDb(): Db {
  const db = new DatabaseSync(':memory:')
  return {
    async exec(sql) {
      db.exec(sql)
    },
    async run(sql, params: SqlValue[] = []) {
      const result = db.prepare(sql).run(...params)
      return { changes: Number(result.changes), lastInsertRowId: Number(result.lastInsertRowid) }
    },
    async getAll<T>(sql: string, params: SqlValue[] = []) {
      return db.prepare(sql).all(...params) as T[]
    },
    async getFirst<T>(sql: string, params: SqlValue[] = []) {
      return (db.prepare(sql).get(...params) as T | undefined) ?? null
    },
    async transaction(fn) {
      db.exec('BEGIN')
      try {
        await fn()
        db.exec('COMMIT')
      } catch (error) {
        db.exec('ROLLBACK')
        throw error
      }
    },
  }
}
```

```ts
import type { SQLiteDatabase } from 'expo-sqlite'
import type { Db, SqlValue } from './db'

export function fromExpo(db: SQLiteDatabase): Db {
  return {
    exec: (sql) => db.execAsync(sql),
    async run(sql, params: SqlValue[] = []) {
      const result = await db.runAsync(sql, params)
      return { changes: result.changes, lastInsertRowId: result.lastInsertRowId }
    },
    getAll: <T>(sql: string, params: SqlValue[] = []) => db.getAllAsync<T>(sql, params),
    getFirst: <T>(sql: string, params: SqlValue[] = []) => db.getFirstAsync<T>(sql, params),
    transaction: (fn) => db.withTransactionAsync(fn),
  }
}
```

- [ ] **Step 8: Migrações** — `src/lib/db/migrations.ts`:

```ts
import type { Db } from './db'
import { PRESET_THEMES } from './presets'

const MIGRATIONS: ((db: Db) => Promise<void>)[] = [
  async (db) => {
    await db.exec(`
      CREATE TABLE books (
        id TEXT PRIMARY KEY NOT NULL,
        title TEXT NOT NULL,
        author TEXT NOT NULL,
        filePath TEXT NOT NULL,
        coverPath TEXT,
        size INTEGER NOT NULL,
        locations TEXT,
        addedAt INTEGER NOT NULL,
        lastOpenedAt INTEGER
      );
      CREATE TABLE progress (
        bookId TEXT PRIMARY KEY NOT NULL REFERENCES books(id) ON DELETE CASCADE,
        cfi TEXT NOT NULL,
        percent REAL,
        updatedAt INTEGER NOT NULL
      );
      CREATE TABLE themes (
        id TEXT PRIMARY KEY NOT NULL,
        name TEXT NOT NULL,
        background TEXT NOT NULL,
        text TEXT NOT NULL,
        link TEXT NOT NULL,
        fontFamily TEXT NOT NULL,
        fontSize REAL NOT NULL,
        lineHeight REAL NOT NULL,
        margin REAL NOT NULL,
        builtin INTEGER NOT NULL
      );
      CREATE TABLE settings (
        key TEXT PRIMARY KEY NOT NULL,
        value TEXT NOT NULL
      );
    `)
    for (const t of PRESET_THEMES) {
      await db.run(
        'INSERT INTO themes (id, name, background, text, link, fontFamily, fontSize, lineHeight, margin, builtin) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, 1)',
        [t.id, t.name, t.background, t.text, t.link, t.fontFamily, t.fontSize, t.lineHeight, t.margin],
      )
    }
  },
]

export async function migrate(db: Db): Promise<void> {
  // Vale por conexão, então a cada abertura, fora da transação.
  await db.exec('PRAGMA foreign_keys = ON')
  const row = await db.getFirst<{ user_version: number }>('PRAGMA user_version')
  for (let version = row?.user_version ?? 0; version < MIGRATIONS.length; version++) {
    const step = MIGRATIONS[version]
    await db.transaction(async () => {
      await step(db)
      await db.exec(`PRAGMA user_version = ${version + 1}`)
    })
  }
}
```

```ts
// O Hermes não tem TextDecoder (e o TextEncoder não é garantido em todas as
// versões), e os nomes das entradas do zip precisam virar texto igual ao que o
// leitor web lê, para o ID do livro bater.
export function encodeUtf8(text: string): Uint8Array {
  const out: number[] = []
  for (const char of text) {
    const cp = char.codePointAt(0)!
    if (cp < 0x80) out.push(cp)
    else if (cp < 0x800) out.push(0xc0 | (cp >> 6), 0x80 | (cp & 0x3f))
    else if (cp < 0x10000) out.push(0xe0 | (cp >> 12), 0x80 | ((cp >> 6) & 0x3f), 0x80 | (cp & 0x3f))
    else out.push(0xf0 | (cp >> 18), 0x80 | ((cp >> 12) & 0x3f), 0x80 | ((cp >> 6) & 0x3f), 0x80 | (cp & 0x3f))
  }
  return Uint8Array.from(out)
}

export function decodeUtf8(bytes: Uint8Array): string {
  let out = ''
  let i = 0
  while (i < bytes.length) {
    const b = bytes[i++]
    let cp: number
    if (b < 0x80) cp = b
    else if (b < 0xe0) cp = ((b & 0x1f) << 6) | (bytes[i++] & 0x3f)
    else if (b < 0xf0) cp = ((b & 0x0f) << 12) | ((bytes[i++] & 0x3f) << 6) | (bytes[i++] & 0x3f)
    else cp = ((b & 0x07) << 18) | ((bytes[i++] & 0x3f) << 12) | ((bytes[i++] & 0x3f) << 6) | (bytes[i++] & 0x3f)
    out += String.fromCodePoint(cp)
  }
  return out
}
```

```ts
import { sha256, toHex } from './sha256'
import { decodeUtf8, encodeUtf8 } from './utf8'

// O ID do livro tem que ser o mesmo em todo aparelho que tem o mesmo livro —
// inclusive no leitor web, que reescreve as folhas de estilo ao importar. Por
// isso ele cobre o que nenhum dos dois muda: caminho, CRC-32 e tamanho de cada
// entrada do zip, exceto folhas de estilo e mimetype. Mesmo algoritmo de
// leitor_epub/src/lib/epub/book-id.ts; os três números vêm do diretório
// central, sem descompactar nada.
export function bookIdFor(bytes: Uint8Array): string {
  const entries = readEntries(bytes).filter(
    (entry) => !entry.name.endsWith('/') && entry.name !== 'mimetype' && !/\.css$/i.test(entry.name),
  )
  entries.sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0))
  const manifest = entries
    .map((entry) => `${entry.name}\0${entry.crc32.toString(16).padStart(8, '0')}\0${entry.size}`)
    .join('\n')
  return toHex(sha256(encodeUtf8(manifest)))
}

interface ZipEntry {
  name: string
  crc32: number
  size: number
}

const END_OF_DIRECTORY = 0x06054b50
const DIRECTORY_ENTRY = 0x02014b50
// O registro final tem 22 bytes mais um comentário de até 65535.
const END_SEARCH = 22 + 0xffff

function readEntries(bytes: Uint8Array): ZipEntry[] {
  const tail = bytes.subarray(Math.max(0, bytes.length - END_SEARCH))
  const tailView = new DataView(tail.buffer, tail.byteOffset, tail.byteLength)
  let end = -1
  for (let i = tail.length - 22; i >= 0; i--) {
    if (tailView.getUint32(i, true) === END_OF_DIRECTORY) {
      end = i
      break
    }
  }
  if (end < 0) throw new Error('Não é um arquivo zip')
  const count = tailView.getUint16(end + 10, true)
  const size = tailView.getUint32(end + 12, true)
  const offset = tailView.getUint32(end + 16, true)
  if (count === 0xffff || size === 0xffffffff || offset === 0xffffffff) throw new Error('Zip64 não suportado')

  const directory = bytes.subarray(offset, offset + size)
  const view = new DataView(directory.buffer, directory.byteOffset, directory.byteLength)
  const entries: ZipEntry[] = []
  let position = 0
  for (let n = 0; n < count; n++) {
    if (position + 46 > directory.length || view.getUint32(position, true) !== DIRECTORY_ENTRY) {
      throw new Error('Diretório do zip corrompido')
    }
    const nameLength = view.getUint16(position + 28, true)
    const extraLength = view.getUint16(position + 30, true)
    const commentLength = view.getUint16(position + 32, true)
    entries.push({
      name: decodeUtf8(directory.subarray(position + 46, position + 46 + nameLength)),
      crc32: view.getUint32(position + 16, true),
      size: view.getUint32(position + 24, true),
    })
    position += 46 + nameLength + extraLength + commentLength
  }
  return entries
}
```

```ts
import { XMLParser } from 'fast-xml-parser'
import JSZip from 'jszip'

export class InvalidEpubError extends Error {}

export class ProtectedEpubError extends InvalidEpubError {
  constructor() {
    super('Livro protegido por DRM')
  }
}

export interface ParsedEpub {
  title: string
  author: string
  cover: { bytes: Uint8Array; extension: string } | null
}

type XmlNode = Record<string, unknown> & { '#text'?: string }

const ARRAYS = new Set(['title', 'creator', 'meta', 'item', 'rootfile', 'EncryptionMethod'])

const parser = new XMLParser({
  ignoreAttributes: false,
  attributeNamePrefix: '@_',
  removeNSPrefix: true,
  parseTagValue: false,
  alwaysCreateTextNode: true,
  isArray: (name) => ARRAYS.has(name),
})

// Ofuscação de fonte não é DRM: o texto continua legível.
const FONT_OBFUSCATION = new Set(['http://www.idpf.org/2008/embedding', 'http://ns.adobe.com/pdf/enc#RC'])

const IMAGE_EXTENSIONS: Record<string, string> = {
  'image/jpeg': 'jpg',
  'image/png': 'png',
  'image/gif': 'gif',
  'image/webp': 'webp',
  'image/svg+xml': 'svg',
}

export async function parseEpub(bytes: Uint8Array, fileName: string): Promise<ParsedEpub> {
  let zip: JSZip
  try {
    zip = await JSZip.loadAsync(bytes)
  } catch {
    throw new InvalidEpubError('Não é um arquivo EPUB')
  }
  const mimetype = await zip.file('mimetype')?.async('string')
  if (mimetype !== undefined && mimetype.trim() !== 'application/epub+zip') {
    throw new InvalidEpubError('Não é um arquivo EPUB')
  }
  await assertNotProtected(zip)

  const containerXml = await zip.file('META-INF/container.xml')?.async('string')
  const rootfile = containerXml
    ? (findAll(parser.parse(containerXml), 'rootfile')[0] as XmlNode | undefined)
    : undefined
  const opfPath = rootfile?.['@_full-path'] as string | undefined
  const opfXml = opfPath ? await zip.file(opfPath)?.async('string') : undefined
  if (!opfPath || !opfXml) throw new InvalidEpubError('EPUB sem documento de pacote (OPF)')

  const pkg = (parser.parse(opfXml).package ?? {}) as XmlNode
  const metadata = (pkg.metadata ?? {}) as XmlNode
  const metas = (metadata.meta ?? []) as XmlNode[]
  const items = ((pkg.manifest as XmlNode | undefined)?.item ?? []) as XmlNode[]

  const refinement = (element: XmlNode, property: string) =>
    metas
      .find((meta) => meta['@_refines'] === `#${element['@_id']}` && meta['@_property'] === property)
      ?.['#text']?.trim()

  const titles = (metadata.title ?? []) as XmlNode[]
  const main = titles.find((title) => refinement(title, 'title-type') === 'main') ?? titles[0]
  const authors = ((metadata.creator ?? []) as XmlNode[])
    .filter((creator) => {
      const role = (creator['@_role'] as string | undefined) || refinement(creator, 'role')
      return !role || role === 'aut'
    })
    .map((creator) => creator['#text']?.trim() ?? '')
    .filter(Boolean)

  return {
    title: main?.['#text']?.trim() || fileName.replace(/\.epub$/i, ''),
    author: authors.join(' & ') || 'Autor desconhecido',
    cover: await readCover(zip, opfPath, items, metas),
  }
}

async function assertNotProtected(zip: JSZip) {
  // rights.xml: licença da Adobe; sinf.xml: da Apple.
  if (zip.file('META-INF/rights.xml') || zip.file('META-INF/sinf.xml')) throw new ProtectedEpubError()
  const encryption = await zip.file('META-INF/encryption.xml')?.async('string')
  if (!encryption) return
  for (const method of findAll(parser.parse(encryption), 'EncryptionMethod') as XmlNode[]) {
    if (!FONT_OBFUSCATION.has((method['@_Algorithm'] as string | undefined) ?? '')) throw new ProtectedEpubError()
  }
}

async function readCover(zip: JSZip, opfPath: string, items: XmlNode[], metas: XmlNode[]) {
  const coverId = metas.find((meta) => meta['@_name'] === 'cover')?.['@_content']
  const item =
    items.find((i) =>
      String(i['@_properties'] ?? '')
        .split(/\s+/)
        .includes('cover-image'),
    ) ?? items.find((i) => i['@_id'] === coverId)
  const href = item?.['@_href'] as string | undefined
  if (!href) return null
  const path = resolvePath(opfPath, decodeURIComponent(href))
  const bytes = await zip.file(path)?.async('uint8array')
  if (!bytes) return null
  const fromName = /\.([a-z0-9]+)$/i.exec(href)?.[1]?.toLowerCase()
  const extension =
    IMAGE_EXTENSIONS[String(item?.['@_media-type'])] ?? (fromName === 'jpeg' ? 'jpg' : fromName) ?? 'img'
  return { bytes, extension }
}

function resolvePath(opfPath: string, href: string): string {
  const parts = opfPath.split('/').slice(0, -1)
  for (const segment of href.split('/')) {
    if (segment === '..') parts.pop()
    else if (segment !== '.' && segment !== '') parts.push(segment)
  }
  return parts.join('/')
}

function findAll(node: unknown, name: string): unknown[] {
  if (!node || typeof node !== 'object') return []
  const found: unknown[] = []
  for (const [key, value] of Object.entries(node)) {
    if (key === name) found.push(...(Array.isArray(value) ? value : [value]))
    else found.push(...findAll(value, name))
  }
  return found
}
```

```ts
// Caminhos relativos ao documentDirectory: o absoluto pode mudar entre
// versões do app no iOS, e o banco guardaria um caminho que não existe mais.
export function fileAt(relativePath: string): File {
  return new File(Paths.document, relativePath)
}

function ensureDirectory(name: string) {
  new Directory(Paths.document, name).create({ idempotent: true, intermediates: true })
}

export function readBytes(uri: string): Promise<Uint8Array> {
  return new File(uri).bytes()
}

export function readBase64(relativePath: string): Promise<string> {
  return fileAt(relativePath).base64()
}

export async function storeBook(id: string, sourceUri: string): Promise<string> {
  ensureDirectory('books')
  const path = `books/${id}.epub`
  await new File(sourceUri).copy(fileAt(path), { overwrite: true })
  return path
}

export async function storeCover(id: string, bytes: Uint8Array, extension: string): Promise<string> {
  ensureDirectory('covers')
  const path = `covers/${id}.${extension}`
  const file = fileAt(path)
  file.create({ overwrite: true })
  await file.write(bytes)
  return path
}

export function deleteFiles(paths: (string | null)[]): void {
  for (const path of paths) {
    if (!path) continue
    const file = fileAt(path)
    if (file.exists) file.delete()
  }
}
```

```ts
import { deleteBook, getBook, insertBook, type Book } from './db/books'
import type { Db } from './db/db'
import { bookIdFor } from './epub/book-id'
import { parseEpub } from './epub/parse'

export interface PickedFile {
  uri: string
  name: string
}

export interface ImportDeps {
  db: Db
  readBytes(uri: string): Promise<Uint8Array>
  storeBook(id: string, sourceUri: string): Promise<string>
  storeCover(id: string, bytes: Uint8Array, extension: string): Promise<string>
  deleteFiles(paths: (string | null)[]): void
  now(): number
}

export interface ImportSummary {
  imported: string[]
  duplicates: string[]
  invalid: { name: string; reason: string }[]
}

export async function importBooks(deps: ImportDeps, files: PickedFile[]): Promise<ImportSummary> {
  const summary: ImportSummary = { imported: [], duplicates: [], invalid: [] }
  for (const file of files) {
    try {
      const bytes = await deps.readBytes(file.uri)
      const parsed = await parseEpub(bytes, file.name)
      const id = bookIdFor(bytes)
      if (await getBook(deps.db, id)) {
        summary.duplicates.push(parsed.title)
        continue
      }
      const stored: string[] = []
      try {
        const filePath = await deps.storeBook(id, file.uri)
        stored.push(filePath)
        const coverPath = parsed.cover ? await deps.storeCover(id, parsed.cover.bytes, parsed.cover.extension) : null
        if (coverPath) stored.push(coverPath)
        await insertBook(deps.db, {
          id,
          title: parsed.title,
          author: parsed.author,
          filePath,
          coverPath,
          size: bytes.length,
          addedAt: deps.now(),
        })
      } catch (error) {
        deps.deleteFiles(stored)
        throw error
      }
      summary.imported.push(parsed.title)
    } catch (error) {
      summary.invalid.push({ name: file.name, reason: error instanceof Error ? error.message : String(error) })
    }
  }
  return summary
}

export async function removeBook(deps: Pick<ImportDeps, 'db' | 'deleteFiles'>, book: Book): Promise<void> {
  await deleteBook(deps.db, book.id)
  deps.deleteFiles([book.filePath, book.coverPath])
}

export function formatSummary(summary: ImportSummary): string {
  const lines: string[] = []
  if (summary.imported.length) {
    lines.push(`${summary.imported.length} ${summary.imported.length === 1 ? 'importado' : 'importados'}.`)
  }
  if (summary.duplicates.length) {
    lines.push(`${summary.duplicates.length} já estava na biblioteca: ${summary.duplicates.join(', ')}`)
  }
  for (const item of summary.invalid) lines.push(`Não importado: ${item.name} (${item.reason})`)
  return lines.join('\n') || 'Nada importado.'
}
```

```ts
import { isFontId } from './fonts'
import type { ReaderTheme } from './theme'

export type Command =
  | { type: 'open'; base64: string; cfi: string | null; locations: string | null }
  | { type: 'next' }
  | { type: 'prev' }
  | { type: 'goTo'; cfi: string }
  | { type: 'setTheme'; theme: ReaderTheme }

export type ReaderEvent =
  | { type: 'ready' }
  | { type: 'relocated'; cfi: string; percent: number | null }
  | { type: 'locations'; data: string }
  | { type: 'centerTap' }
  | { type: 'error'; message: string }

type Fields = Record<string, unknown>

const isString = (value: unknown): value is string => typeof value === 'string'
const isNumber = (value: unknown): value is number => typeof value === 'number' && Number.isFinite(value)
const isNullableString = (value: unknown): value is string | null => value === null || isString(value)

function parseObject(raw: string): Fields | null {
  try {
    const value: unknown = JSON.parse(raw)
    return value && typeof value === 'object' && !Array.isArray(value) ? (value as Fields) : null
  } catch {
    return null
  }
}

export function isReaderTheme(value: unknown): value is ReaderTheme {
  if (!value || typeof value !== 'object') return false
  const t = value as Fields
  return (
    isString(t.background) &&
    isString(t.text) &&
    isString(t.link) &&
    isFontId(t.fontFamily) &&
    isNumber(t.fontSize) &&
    isNumber(t.lineHeight) &&
    isNumber(t.margin)
  )
}

function pickTheme(t: ReaderTheme): ReaderTheme {
  const { background, text, link, fontFamily, fontSize, lineHeight, margin } = t
  return { background, text, link, fontFamily, fontSize, lineHeight, margin }
}

export function parseCommand(raw: string): Command | null {
  const m = parseObject(raw)
  if (!m) return null
  switch (m.type) {
    case 'open':
      return isString(m.base64) && isNullableString(m.cfi) && isNullableString(m.locations)
        ? { type: 'open', base64: m.base64, cfi: m.cfi, locations: m.locations }
        : null
    case 'next':
    case 'prev':
      return { type: m.type }
    case 'goTo':
      return isString(m.cfi) ? { type: 'goTo', cfi: m.cfi } : null
    case 'setTheme':
      return isReaderTheme(m.theme) ? { type: 'setTheme', theme: pickTheme(m.theme) } : null
    default:
      return null
  }
}

export function parseEvent(raw: string): ReaderEvent | null {
  const m = parseObject(raw)
  if (!m) return null
  switch (m.type) {
    case 'ready':
    case 'centerTap':
      return { type: m.type }
    case 'relocated':
      return isString(m.cfi) && (m.percent === null || (isNumber(m.percent) && m.percent >= 0 && m.percent <= 1))
        ? { type: 'relocated', cfi: m.cfi, percent: m.percent }
        : null
    case 'locations':
      return isString(m.data) ? { type: 'locations', data: m.data } : null
    case 'error':
      return isString(m.message) ? { type: 'error', message: m.message } : null
    default:
      return null
  }
}

// O livro vai em base64 numa mensagem só; acima de alguns MB uma única chamada
// de injectJavaScript fica lenta ou falha. Pedaços menores, remontados na página.
export const CHUNK_SIZE = 512 * 1024

export interface Chunk {
  id: number
  index: number
  total: number
  data: string
}

let nextId = 1

export function chunkMessage(message: string, size = CHUNK_SIZE): Chunk[] {
  const id = nextId++
  const total = Math.max(1, Math.ceil(message.length / size))
  return Array.from({ length: total }, (_, index) => ({
    id,
    index,
    total,
    data: message.slice(index * size, (index + 1) * size),
  }))
}

function isChunk(value: unknown): value is Chunk {
  if (!value || typeof value !== 'object') return false
  const c = value as Fields
  return isNumber(c.id) && isNumber(c.index) && isNumber(c.total) && isString(c.data) && c.index < c.total
}

export class Assembler {
  private pending = new Map<number, { parts: string[]; received: number }>()

  push(raw: unknown): string | null {
    if (!isChunk(raw)) return null
    if (raw.total === 1) return raw.data
    const entry = this.pending.get(raw.id) ?? { parts: new Array<string>(raw.total), received: 0 }
    if (entry.parts[raw.index] === undefined) entry.received++
    entry.parts[raw.index] = raw.data
    this.pending.set(raw.id, entry)
    if (entry.received < raw.total) return null
    this.pending.delete(raw.id)
    return entry.parts.join('')
  }
}
```

```ts
export type Gesture = 'next' | 'prev' | 'centerTap' | null

const SWIPE_MIN = 40
const TAP_MAX = 10
const EDGE = 0.3

// dx/dy: deslocamento do dedo; x: onde o dedo saiu, na largura da tela.
export function classifyGesture({ dx, dy, x, width }: { dx: number; dy: number; x: number; width: number }): Gesture {
  if (Math.abs(dx) >= SWIPE_MIN && Math.abs(dx) > Math.abs(dy)) return dx < 0 ? 'next' : 'prev'
  if (Math.abs(dx) <= TAP_MAX && Math.abs(dy) <= TAP_MAX) {
    if (x < width * EDGE) return 'prev'
    if (x > width * (1 - EDGE)) return 'next'
    return 'centerTap'
  }
  return null
}
```

```ts
import ePub, { type Book, type Contents, type Rendition } from 'epubjs'
import { fontCss } from '../../src/reader/fonts'
import { classifyGesture } from '../../src/reader/gestures'
import { Assembler, parseCommand, type Command, type ReaderEvent } from '../../src/reader/protocol'
import type { ReaderTheme } from '../../src/reader/theme'
import fontsCss from './fonts.css?inline'

declare global {
  interface Window {
    ReactNativeWebView?: { postMessage(data: string): void }
    __rnReceive?: (chunk: unknown) => void
  }
}

const LOCATION_CHARS = 1024
const viewer = document.getElementById('viewer')!

let book: Book | null = null
let rendition: Rendition | null = null
let locations: Book['locations'] | null = null
let theme: ReaderTheme | null = null

function send(event: ReaderEvent) {
  window.ReactNativeWebView?.postMessage(JSON.stringify(event))
}

function percentOf(cfi: string): number | null {
  return locations ? locations.percentageFromCfi(cfi) : null
}

function applyTheme(t: ReaderTheme) {
  document.body.style.background = t.background
  viewer.style.left = `${t.margin}px`
  viewer.style.right = `${t.margin}px`
  if (!rendition) return
  rendition.themes.default({
    body: {
      background: `${t.background} !important`,
      color: `${t.text} !important`,
      'font-family': `${fontCss(t.fontFamily)} !important`,
    },
    // O CSS do livro costuma pôr line-height direto nos elementos, o que vence
    // um valor herdado do body; só mirando neles a entrelinha muda.
    'p, li, blockquote, div, span, td': { 'line-height': `${t.lineHeight} !important` },
    a: { color: `${t.link} !important` },
  })
  rendition.themes.fontSize(`${t.fontSize}px`)
  rendition.resize()
}

function registerGestures(contents: Contents) {
  const doc = contents.document
  let start: { x: number; y: number } | null = null
  doc.addEventListener(
    'touchstart',
    (event) => {
      start = event.touches.length === 1 ? { x: event.touches[0].clientX, y: event.touches[0].clientY } : null
    },
    { passive: true },
  )
  doc.addEventListener('touchend', (event) => {
    const touch = event.changedTouches[0]
    if (!start || !touch) return
    if ((event.target as Element | null)?.closest?.('a')) return
    // clientX é relativo ao iframe, que no modo paginado é bem mais largo que
    // a tela e fica deslocado; somando a posição dele vira posição na tela.
    const frameLeft = (doc.defaultView?.frameElement as HTMLElement | null)?.getBoundingClientRect().left ?? 0
    const gesture = classifyGesture({
      dx: touch.clientX - start.x,
      dy: touch.clientY - start.y,
      x: frameLeft + touch.clientX,
      width: window.innerWidth,
    })
    start = null
    if (gesture === 'next') void rendition?.next()
    else if (gesture === 'prev') void rendition?.prev()
    else if (gesture === 'centerTap') send({ type: 'centerTap' })
  })
}

function base64ToArrayBuffer(base64: string): ArrayBuffer {
  const binary = atob(base64)
  const bytes = new Uint8Array(binary.length)
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i)
  return bytes.buffer
}

async function loadLocations(buffer: ArrayBuffer, saved: string | null) {
  if (!book) return
  if (saved) {
    book.locations.load(saved)
    locations = book.locations
  } else {
    const locationsBook = ePub(buffer.slice(0))
    await locationsBook.ready
    await locationsBook.locations.generate(LOCATION_CHARS)
    locations = locationsBook.locations
    send({ type: 'locations', data: locationsBook.locations.save() })
  }
  const cfi = rendition?.location?.start?.cfi
  if (cfi) send({ type: 'relocated', cfi, percent: percentOf(cfi) })
}

async function open(base64: string, cfi: string | null, savedLocations: string | null) {
  const buffer = base64ToArrayBuffer(base64)
  book = ePub(buffer)
  const opened = book
  // Um arquivo que não é EPUB nunca resolve book.ready; o epub.js só avisa por este evento.
  await new Promise<void>((resolve, reject) => {
    opened.on('openFailed', reject)
    opened.ready.then(() => resolve(), reject)
  })
  rendition = book.renderTo(viewer, { width: '100%', height: '100%', flow: 'paginated', spread: 'none' })
  const current = rendition
  rendition.hooks.content.register((contents: Contents) => {
    contents.addStylesheetCss(fontsCss, 'reader-fonts')
    registerGestures(contents)
    // Fonte que chega depois do layout muda o número de páginas, e o epub.js
    // 0.3.93 não percebe; resizeCheck remede.
    const refit = () => {
      ;(contents as unknown as { resizeCheck(): void }).resizeCheck()
      void current.reportLocation()
    }
    contents.document.fonts?.forEach((face) => {
      face.loaded.then(refit, () => {})
    })
  })
  if (theme) applyTheme(theme)
  rendition.on('relocated', (location: { start: { cfi: string } }) => {
    send({ type: 'relocated', cfi: location.start.cfi, percent: percentOf(location.start.cfi) })
  })
  await rendition.display(cfi ?? undefined)
  void loadLocations(buffer, savedLocations).catch(() => {})
}

async function handle(command: Command) {
  switch (command.type) {
    case 'open':
      return open(command.base64, command.cfi, command.locations)
    case 'next':
      return rendition?.next()
    case 'prev':
      return rendition?.prev()
    case 'goTo':
      return rendition?.display(command.cfi)
    case 'setTheme':
      theme = command.theme
      applyTheme(theme)
  }
}

const assembler = new Assembler()
window.__rnReceive = (chunk) => {
  const raw = assembler.push(chunk)
  if (raw === null) return
  const command = parseCommand(raw)
  if (!command) return
  handle(command).catch((error: unknown) =>
    send({ type: 'error', message: error instanceof Error ? error.message : String(error) }),
  )
}

send({ type: 'ready' })
```

```tsx
import { useImperativeHandle, useRef, type Ref } from 'react'
import { StyleSheet } from 'react-native'
import { WebView } from 'react-native-webview'
import { READER_HTML } from '@/reader/bundle.generated'
import { chunkMessage, parseEvent, type Command, type ReaderEvent } from '@/reader/protocol'

export interface ReaderHandle {
  send(command: Command): void
}

interface Props {
  ref: Ref<ReaderHandle>
  background: string
  onEvent(event: ReaderEvent): void
}

export function Reader({ ref, background, onEvent }: Props) {
  const webview = useRef<WebView>(null)

  useImperativeHandle(
    ref,
    () => ({
      send(command) {
        for (const chunk of chunkMessage(JSON.stringify(command))) {
          // Antes da página carregar __rnReceive ainda não existe; o app só
          // manda o livro depois do evento ready.
          webview.current?.injectJavaScript(`window.__rnReceive && window.__rnReceive(${JSON.stringify(chunk)}); true;`)
        }
      },
    }),
    [],
  )

  return (
    <WebView
      ref={webview}
      source={{ html: READER_HTML }}
      originWhitelist={['*']}
      style={[styles.webview, { backgroundColor: background }]}
      onMessage={(event) => {
        const parsed = parseEvent(event.nativeEvent.data)
        if (parsed) onEvent(parsed)
      }}
    />
  )
}

const styles = StyleSheet.create({ webview: { flex: 1 } })
```

```tsx
import { router, useLocalSearchParams } from 'expo-router'
import { useCallback, useEffect, useRef, useState } from 'react'
import { AppState, Pressable, StyleSheet, Text, View } from 'react-native'
import { SafeAreaView } from 'react-native-safe-area-context'
import { Reader, type ReaderHandle } from '@/components/Reader'
import { getBook, markOpened, saveLocations, type Book } from '@/lib/db/books'
import { PRESET_THEMES } from '@/lib/db/presets'
import { getProgress, saveProgress } from '@/lib/db/progress'
import { useDb } from '@/lib/db/provider'
import { toReaderTheme } from '@/lib/db/themes'
import { readBase64 } from '@/lib/files'
import type { ReaderEvent } from '@/reader/protocol'

const SAVE_DELAY_MS = 1000

export default function BookScreen() {
  const { id } = useLocalSearchParams<{ id: string }>()
  const db = useDb()
  const reader = useRef<ReaderHandle>(null)
  const theme = PRESET_THEMES[0]
  const [book, setBook] = useState<Book | null>(null)
  const [percent, setPercent] = useState<number | null>(null)
  const [barVisible, setBarVisible] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const pending = useRef<{ cfi: string; percent: number | null } | null>(null)
  const timer = useRef<ReturnType<typeof setTimeout> | undefined>(undefined)

  const flush = useCallback(async () => {
    clearTimeout(timer.current)
    const position = pending.current
    if (!position) return
    pending.current = null
    await saveProgress(db, { bookId: id, ...position }, Date.now())
  }, [db, id])

  // O sistema pode matar o app em segundo plano sem avisar: grava na hora.
  useEffect(() => {
    const subscription = AppState.addEventListener('change', (state) => {
      if (state !== 'active') void flush()
    })
    return () => {
      subscription.remove()
      void flush()
    }
  }, [flush])

  const onEvent = useCallback(
    async (event: ReaderEvent) => {
      switch (event.type) {
        case 'ready': {
          const found = await getBook(db, id)
          if (!found) return setError('Livro não encontrado.')
          setBook(found)
          const [progress, base64] = await Promise.all([getProgress(db, id), readBase64(found.filePath)])
          reader.current?.send({ type: 'setTheme', theme: toReaderTheme(theme) })
          reader.current?.send({ type: 'open', base64, cfi: progress?.cfi ?? null, locations: found.locations })
          setPercent(progress?.percent ?? null)
          await markOpened(db, id, Date.now())
          return
        }
        case 'relocated':
          pending.current = { cfi: event.cfi, percent: event.percent }
          if (event.percent !== null) setPercent(event.percent)
          clearTimeout(timer.current)
          timer.current = setTimeout(() => void flush(), SAVE_DELAY_MS)
          return
        case 'locations':
          return saveLocations(db, id, event.data)
        case 'centerTap':
          return setBarVisible((visible) => !visible)
        case 'error':
          return setError(event.message)
      }
    },
    [db, id, flush, theme],
  )

  if (error) {
    return (
      <SafeAreaView style={styles.center}>
        <Text style={styles.errorText}>Não foi possível abrir o livro: {error}</Text>
        <Pressable onPress={() => router.back()} style={styles.button}>
          <Text>Voltar</Text>
        </Pressable>
      </SafeAreaView>
    )
  }

  return (
    <SafeAreaView style={[styles.screen, { backgroundColor: theme.background }]}>
      <Reader ref={reader} background={theme.background} onEvent={onEvent} />
      {barVisible && (
        <View style={styles.bar}>
          <Pressable onPress={() => router.back()} style={styles.button}>
            <Text>Voltar</Text>
          </Pressable>
          <Text style={styles.barTitle} numberOfLines={1}>
            {book?.title}
          </Text>
          <Text>{percent === null ? '' : `${Math.round(percent * 100)}%`}</Text>
        </View>
      )}
    </SafeAreaView>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1 },
  center: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24, gap: 16 },
  errorText: { textAlign: 'center' },
  bar: {
    position: 'absolute',
    top: 0,
    left: 0,
    right: 0,
    flexDirection: 'row',
    alignItems: 'center',
    gap: 12,
    padding: 12,
    backgroundColor: 'rgba(255,255,255,0.95)',
  },
  barTitle: { flex: 1, fontWeight: '600' },
  button: { paddingHorizontal: 12, paddingVertical: 6, borderRadius: 8, backgroundColor: '#f0e6ff' },
})
```

```ts
import { useStore } from 'zustand'
import { createStore } from 'zustand/vanilla'
import type { Db } from '@/lib/db/db'
import { DEFAULT_THEME_ID, PRESET_THEMES } from '@/lib/db/presets'
import { getSetting, setSetting } from '@/lib/db/settings'
import { deleteTheme, listThemes, saveTheme, type Theme } from '@/lib/db/themes'
import type { ReaderTheme } from '@/reader/theme'

export const LIMITS = {
  fontSize: { min: 12, max: 32, step: 1 },
  lineHeight: { min: 1.2, max: 2.2, step: 0.1 },
  margin: { min: 8, max: 48, step: 4 },
} as const

export function adjust(value: number, direction: 1 | -1, limits: { min: number; max: number; step: number }): number {
  const next = Math.round((value + direction * limits.step) * 10) / 10
  return Math.min(limits.max, Math.max(limits.min, next))
}

interface ThemeState {
  themes: Theme[]
  active: Theme
  load(db: Db): Promise<void>
  select(db: Db, id: string): Promise<void>
  update(db: Db, patch: Partial<ReaderTheme>): Promise<void>
  remove(db: Db, id: string): Promise<void>
}

export function createThemeStore(now: () => number = Date.now) {
  return createStore<ThemeState>()((set, get) => ({
    themes: PRESET_THEMES,
    active: PRESET_THEMES[0],

    async load(db) {
      const themes = await listThemes(db)
      const activeId = (await getSetting(db, 'activeThemeId')) ?? DEFAULT_THEME_ID
      set({ themes, active: themes.find((t) => t.id === activeId) ?? themes[0] })
    },

    async select(db, id) {
      const theme = get().themes.find((t) => t.id === id)
      if (!theme) return
      await setSetting(db, 'activeThemeId', id)
      set({ active: theme })
    },

    async update(db, patch) {
      const { active, themes } = get()
      // Tema pronto não se edita: o primeiro ajuste cria uma cópia do usuário.
      const next: Theme = active.builtin
        ? { ...active, ...patch, id: `custom-${now().toString(36)}`, name: `${active.name} (meu)`, builtin: false }
        : { ...active, ...patch }
      await saveTheme(db, next)
      if (active.builtin) await setSetting(db, 'activeThemeId', next.id)
      set({
        active: next,
        themes: active.builtin ? [...themes, next] : themes.map((t) => (t.id === next.id ? next : t)),
      })
    },

    async remove(db, id) {
      await deleteTheme(db, id)
      const themes = get().themes.filter((t) => t.id !== id)
      if (get().active.id === id) {
        await setSetting(db, 'activeThemeId', DEFAULT_THEME_ID)
        set({ themes, active: themes.find((t) => t.id === DEFAULT_THEME_ID) ?? themes[0] })
      } else {
        set({ themes })
      }
    },
  }))
}

export const themeStore = createThemeStore()

export function useThemeStore<T>(selector: (state: ThemeState) => T): T {
  return useStore(themeStore, selector)
}
```
