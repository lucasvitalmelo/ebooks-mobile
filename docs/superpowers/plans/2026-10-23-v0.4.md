# v0.4 — Busca, notas, editar/exportar, tema Preto e temperatura da luz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trazer do leitor web a busca no livro, as notas nos grifos, editar título/autor/capa e exportar o `.epub`; e acrescentar o tema Preto (OLED) e um ajuste de temperatura da luz.

**Architecture:** A busca roda na página do leitor, num segundo `Book` do epub.js aberto dos mesmos bytes (como no web), e volta ao RN por um evento `searchResults`. Notas são uma coluna nova em `highlights`. Editar é o `edit.ts` do web portado para o RN com `@xmldom/xmldom` no lugar do `DOMParser` e a capa já redimensionada pelo `expo-image-manipulator`. Exportar copia o arquivo para o cache com o nome do web e abre o compartilhamento do Android. A temperatura da luz é um filtro âmbar translúcido sobre o app, que não recebe toques.

**Tech Stack:** Expo SDK 58, TypeScript, epub.js 0.3.93, react-native-webview 14, expo-sqlite, Zustand, Jest, mais `@xmldom/xmldom`, `expo-image-picker`, `expo-image-manipulator`, `expo-sharing`.

```ts
export interface SearchResult {
  cfi: string
  excerpt: string
  chapterLabel: string | null
}

export function splitMatch(excerpt: string, query: string): { before: string; match: string; after: string } {
  const at = query ? excerpt.toLocaleLowerCase('pt-BR').indexOf(query.toLocaleLowerCase('pt-BR')) : -1
  if (at < 0) return { before: excerpt, match: '', after: '' }
  return {
    before: excerpt.slice(0, at),
    match: excerpt.slice(at, at + query.length),
    after: excerpt.slice(at + query.length),
  }
}

export function groupByChapter(results: SearchResult[]): { chapterLabel: string | null; results: SearchResult[] }[] {
  const groups: { chapterLabel: string | null; results: SearchResult[] }[] = []
  for (const result of results) {
    const last = groups[groups.length - 1]
    if (last && last.chapterLabel === result.chapterLabel) last.results.push(result)
    else groups.push({ chapterLabel: result.chapterLabel, results: [result] })
  }
  return groups
}
```

// Caracteres que Windows, macOS ou Android recusam num nome de arquivo.
const UNSAFE_IN_FILE_NAME = /[\\/:*?"<>|\p{Cc}]/gu

export function exportFileName(book: { title: string; author: string }): string {
  const clean = (text: string) => text.replace(UNSAFE_IN_FILE_NAME, '').replace(/\s+/g, ' ').trim()
  const name = [clean(book.title), clean(book.author)].filter(Boolean).join(' - ') || 'livro'
  return `${name.slice(0, 120)}.epub`
}

async function search(id: number, query: string) {
  searchRequest = id

  if (!currentBuffer || query.trim().length < 3) return send({ type: 'searchResults', id, results })
  if (!searchBook) {
    searchBook = ePub(currentBuffer.slice(0))
    await searchBook.ready

    unload(): void
    href: string

  target.spine.each((section: (typeof sections)[number]) => sections.push(section))
  for (const section of sections) {
    if (searchRequest !== id || results.length >= MAX_SEARCH_RESULTS) break
    try {
      await section.load(target.load.bind(target))
      if (searchRequest !== id) break
      const label = tocEntries.find((e) => e.href.split('#')[0] === section.href)?.label ?? null

      }
    } catch (error) {

      section.unload()
    }
  }
  if (searchRequest === id) send({ type: 'searchResults', id, results })
