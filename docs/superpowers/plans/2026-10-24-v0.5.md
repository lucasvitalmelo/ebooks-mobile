# v0.5 — Limpeza do EPUB, escala da fonte e importação de PDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Limpar as folhas de estilo de todo EPUB importado (como o `prepareEpub` do leitor web), corrigir o tamanho de letra dos livros com fonte própria muito grande ou pequena (`fontScale`), e importar PDFs com texto convertendo-os em EPUB.

**Architecture:** A limpeza é o `sanitizeCss` do web portado e aplicado na importação (e uma vez nos livros já importados); só o CSS muda, então ID, posições e grifos continuam valendo. A escala da fonte é medida uma vez por livro dentro da página do leitor (que tem DOM), com o mesmo algoritmo do web, e guardada no banco. O PDF é lido por uma segunda WebView escondida com o pdf.js, que devolve o texto de cada página; o RN monta parágrafos e capítulos e gera um EPUB comum, que segue a importação normal.

**Tech Stack:** Expo SDK 58, TypeScript, epub.js 0.3.93, JSZip, react-native-webview 14, Jest, mais `pdfjs-dist` (no bundle da WebView) e `pdf-lib` (só para gerar o PDF de teste).

## Decisões (spec desta versão)

- **Limpeza na importação:** cada `.css` do EPUB passa pelo `sanitizeCss` do web (tira `color`, `background-color`, `background` sem `url(...)` e `white-space: pre*` fora de `pre`/`code`). Se algo mudou, o EPUB é reempacotado (`repack`, `mimetype` primeiro). Se a limpeza falhar, o livro entra como veio (como no web). O HTML dos capítulos nunca muda.
- **Livros já importados:** coluna `prepared` (migração 4). Ao abrir a Biblioteca, os livros com `prepared = 0` são limpos um por vez em segundo plano (troca atômica do arquivo, `replaceBytes`) e marcados. Falha marca do mesmo jeito (não tenta para sempre) e registra no log.
- **Escala da fonte:** coluna `fontScale` (migração 4). Na primeira abertura de cada livro (`fontScale` nulo), a página mede como o web (`measureFontScale` + `fontScaleFor`: tamanho de letra predominante com o corpo forçado em 100 px; fator só se a diferença passar de 5% e ficar entre 0,5× e 2×), aplica e avisa o app, que guarda. O tamanho aplicado é `tamanho do tema × fontScale`.
- **PDF:**
  - O seletor continua aberto (`*/*`); um arquivo que começa com `%PDF-` é tratado como PDF.
  - Conversão por texto: linhas da mesma altura viram uma linha; um espaço vertical maior que 1,4× o espaçamento comum abre parágrafo novo; hífen no fim de linha antes de minúscula junta a palavra; um parágrafo que termina sem pontuação continua na página seguinte.
  - Tira linhas que são só número de página ("12", "Página 12", "12 de 300") e linhas repetidas no topo ou no rodapé de pelo menos 30% das páginas (mínimo 3), comparadas com os números trocados por `#`.
  - Capítulos: o sumário do PDF (nível de cima) quando existe, com uma parte "Início" se o primeiro capítulo não começa na página 1; sem sumário, partes de 20 páginas ("Páginas 1–20").
  - Título e autor dos metadados do PDF; sem título, o nome do arquivo sem `.pdf`; sem autor, "Autor desconhecido".
  - Capa: a primeira página renderizada em JPEG (largura 1000 px, qualidade 0,85).
  - Durante a conversão, um aviso "Convertendo PDF (página N de M)".
  - PDF só com imagem (menos de 100 caracteres de texto no total): não importa, com "Este PDF não tem texto para converter (é só imagem)." no resumo. OCR fica para depois.
  - O EPUB gerado segue a importação normal (ID, duplicata, capa); exportar devolve o EPUB.
- **Fora desta versão:** OCR, imagens e tabelas do PDF, layout fixo.

import JSZip from 'jszip'
import { repack } from './edit'
import { sanitizeCss } from './sanitize'

// Roda na importação, como o prepareEpub do leitor web: só as folhas de estilo
// mudam, nunca o HTML dos capítulos, então posições e grifos continuam valendo.
// Qualquer falha devolve o arquivo como veio.
export async function prepareEpub(bytes: Uint8Array): Promise<{ bytes: Uint8Array; changed: boolean }> {
  try {
    const zip = await JSZip.loadAsync(bytes)
    const changed = new Map<string, string | Uint8Array>()
    for (const entry of Object.values(zip.files)) {
      if (entry.dir || !/\.css$/i.test(entry.name)) continue
      const original = await entry.async('string')
      const clean = sanitizeCss(original)
      if (clean !== original) changed.set(entry.name, clean)
    }
    if (changed.size === 0) return { bytes, changed: false }
    return { bytes: await repack(zip, changed), changed: true }
  } catch (error) {
    console.warn('Não foi possível limpar o EPUB; mantendo o arquivo original', error)
    return { bytes, changed: false }
  }
}
```

import { listUnprepared, markPrepared } from './db/books'
import type { Db } from './db/db'
import { prepareEpub } from './epub/prepare'

export interface PrepareDeps {
  db: Db
  readFile(path: string): Promise<Uint8Array>
  replaceFile(path: string, bytes: Uint8Array): Promise<void>
}

// Uma vez por livro importado antes da limpeza existir; falha também marca,
// para não tentar o mesmo arquivo a cada abertura da biblioteca.
export async function prepareLibrary(deps: PrepareDeps): Promise<void> {
  for (const book of await listUnprepared(deps.db)) {
    try {
      const { bytes, changed } = await prepareEpub(await deps.readFile(book.filePath))
      if (changed) await deps.replaceFile(book.filePath, bytes)
    } catch (error) {
      console.warn('Não foi possível limpar o livro', book.id, error)
    }
    await markPrepared(deps.db, book.id)
  }
}
```

const RUNNING_MIN = 3
const PAGE_NUMBER = /^(p(á|a)g(ina)?\.?\s*)?#(\s*(de|\/)\s*#)?$/

const keyOf = (text: string) => text.replace(/\d+/g, '#').replace(/\s+/g, ' ').trim().toLowerCase()

export function dropRunningLines(pages: PageText[]): PageText[] {
  const counts = new Map<string, number>()
  for (const page of pages) {
    const edges = new Set([page.lines[0], page.lines[page.lines.length - 1]].filter(Boolean).map((l) => keyOf(l.text)))
    for (const key of edges) counts.set(key, (counts.get(key) ?? 0) + 1)
  }
  const threshold = Math.max(RUNNING_MIN, pages.length * RUNNING_SHARE)
  return pages.map((page) => ({
    lines: page.lines.filter((line, index) => {
      const key = keyOf(line.text)
      if (PAGE_NUMBER.test(key)) return false
      const edge = index === 0 || index === page.lines.length - 1
      return !(edge && (counts.get(key) ?? 0) >= threshold)
    }),
  }))
}

function median(values: number[]): number {
  if (!values.length) return 0
  const sorted = [...values].sort((a, b) => a - b)
  return sorted[Math.floor(sorted.length / 2)]
}

function join(current: string, next: string): string {
  if (current.endsWith('-') && /^[a-zà-ÿ]/.test(next)) return current.slice(0, -1) + next
  return `${current} ${next}`
}

export function paragraphs(lines: Line[]): string[] {
  const gaps = lines
    .slice(1)
    .map((line, i) => line.top - lines[i].top)
    .filter((gap) => gap > 0)
  const spacing = median(gaps)
  const out: string[] = []
  let current = ''
  lines.forEach((line, i) => {
    const text = line.text.replace(/\s+/g, ' ').trim()
    if (!text) return
    const gap = i > 0 ? line.top - lines[i - 1].top : 0
    if (current && spacing > 0 && gap > spacing * PARAGRAPH_GAP) {
      out.push(current)
      current = ''
    }
    current = current ? join(current, text) : text
  })
  if (current) out.push(current)
  return out
}

const ENDS_SENTENCE = /[.!?:;"”»)\]]$/

function pagesToParagraphs(pages: PageText[]): string[] {
  const out: string[] = []
  for (const page of pages) {
    const paras = paragraphs(page.lines)
    if (!paras.length) continue
    const last = out[out.length - 1]
    if (last && !ENDS_SENTENCE.test(last)) {
      out[out.length - 1] = join(last, paras[0])
      out.push(...paras.slice(1))
    } else out.push(...paras)
  }
  return out
}

export function chapters(pages: PageText[], outline: OutlineEntry[]): Chapter[] {
  const starts: OutlineEntry[] = []
  for (const entry of [...outline].sort((a, b) => a.pageIndex - b.pageIndex)) {
    if (entry.pageIndex < 0 || entry.pageIndex >= pages.length) continue
    if (starts.some((s) => s.pageIndex === entry.pageIndex)) continue
    starts.push({ title: entry.title.trim() || `Página ${entry.pageIndex + 1}`, pageIndex: entry.pageIndex })
  }
  const ranges: { title: string; from: number; to: number }[] = []
  if (starts.length) {
    if (starts[0].pageIndex > 0) ranges.push({ title: 'Início', from: 0, to: starts[0].pageIndex })
    starts.forEach((start, i) =>
      ranges.push({ title: start.title, from: start.pageIndex, to: starts[i + 1]?.pageIndex ?? pages.length }),
    )
  } else {
    for (let from = 0; from < pages.length; from += PAGES_PER_PART) {
      const to = Math.min(pages.length, from + PAGES_PER_PART)
      ranges.push({ title: `Páginas ${from + 1}–${to}`, from, to })
    }
  }
  const result = ranges
    .map((range) => ({ title: range.title, paragraphs: pagesToParagraphs(pages.slice(range.from, range.to)) }))
    .filter((chapter) => chapter.paragraphs.length > 0)
  return result
}

<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="${language}" lang="${language}">
<head><title>${escape(chapter.title)}</title></head>
<body>
<h1>${escape(chapter.title)}</h1>
${body}
</body>
</html>
`
}

import type { OutlineEntry, PageText } from '../lib/pdf/layout'

export interface PdfResult {
  title: string | null
  author: string | null
  pages: PageText[]
  outline: OutlineEntry[]
  // JPEG da primeira página, em base64, ou null.
  cover: string | null
}

export type PdfCommand = { type: 'convert'; id: number; base64: string }

export type PdfEvent =
  | { type: 'ready' }
  | { type: 'progress'; id: number; page: number; total: number }
  | ({ type: 'pdfResult'; id: number } & PdfResult)
  | { type: 'pdfError'; id: number; message: string }

type Fields = Record<string, unknown>
const isString = (v: unknown): v is string => typeof v === 'string'
const isNumber = (v: unknown): v is number => typeof v === 'number' && Number.isFinite(v)
const isNullableString = (v: unknown): v is string | null => v === null || isString(v)
const isObject = (v: unknown): v is Fields => Boolean(v) && typeof v === 'object' && !Array.isArray(v)

function parse(raw: string): Fields | null {
  try {
    const value: unknown = JSON.parse(raw)
    return isObject(value) ? value : null
  } catch {
    return null
  }
}

const isLine = (v: unknown) => isObject(v) && isString(v.text) && isNumber(v.top) && isNumber(v.height)
const isPage = (v: unknown) => isObject(v) && Array.isArray(v.lines) && v.lines.every(isLine)
const isOutline = (v: unknown) => isObject(v) && isString(v.title) && Number.isInteger(v.pageIndex)

export function parsePdfCommand(raw: string): PdfCommand | null {
  const m = parse(raw)
  return m && m.type === 'convert' && Number.isInteger(m.id) && isString(m.base64)
    ? { type: 'convert', id: m.id as number, base64: m.base64 }
    : null
}

export function parsePdfEvent(raw: string): PdfEvent | null {
  const m = parse(raw)
  if (!m) return null
  switch (m.type) {
    case 'ready':
      return { type: 'ready' }
    case 'progress':
      return Number.isInteger(m.id) && isNumber(m.page) && isNumber(m.total)
        ? { type: 'progress', id: m.id as number, page: m.page, total: m.total }
        : null
    case 'pdfResult':
      return Number.isInteger(m.id) &&
        isNullableString(m.title) &&
        isNullableString(m.author) &&
        Array.isArray(m.pages) &&
        m.pages.every(isPage) &&
        Array.isArray(m.outline) &&
        m.outline.every(isOutline) &&
        isNullableString(m.cover)
        ? {
            type: 'pdfResult',
            id: m.id as number,
            title: m.title,
            author: m.author,
            pages: m.pages as PageText[],
            outline: m.outline as OutlineEntry[],
            cover: m.cover,
          }
        : null
    case 'pdfError':
      return Number.isInteger(m.id) && isString(m.message)
        ? { type: 'pdfError', id: m.id as number, message: m.message }
        : null
    default:
      return null
  }
}

import { InvalidEpubError } from '../epub/parse'
import { chapters, dropRunningLines } from './layout'

const MIN_TEXT = 100

export class PdfWithoutTextError extends InvalidEpubError {
  constructor() {
    super('Este PDF não tem texto para converter (é só imagem).')
  }
}

// O base64 da capa vem da WebView (canvas.toDataURL); o RN não tem atob garantido no Hermes.
function base64ToBytes(base64: string): Uint8Array {
  const table = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'
  const clean = base64.replace(/[^A-Za-z0-9+/]/g, '')
  const out = new Uint8Array(Math.floor((clean.length * 3) / 4))
  let bits = 0
  let value = 0
  let index = 0
  for (const char of clean) {
    value = (value << 6) | table.indexOf(char)
    bits += 6
    if (bits >= 8) {
      bits -= 8
      out[index++] = (value >> bits) & 0xff
    }
  }
  return out.subarray(0, index)
}

export async function pdfToEpub(result: PdfResult, fileName: string, identifier: string): Promise<Uint8Array> {
  const text = result.pages.reduce((sum, page) => sum + page.lines.reduce((n, l) => n + l.text.trim().length, 0), 0)
  if (text < MIN_TEXT) throw new PdfWithoutTextError()
  const parts = chapters(dropRunningLines(result.pages), result.outline)
  return buildEpub({
    identifier,
    title: result.title?.trim() || fileName.replace(/\.pdf$/i, ''),
    author: result.author?.trim() ?? '',
    language: 'pt-BR',
    chapters: parts,
    cover: result.cover ? { bytes: base64ToBytes(result.cover), extension: 'jpg' } : null,
  })
}

  for (const segment of decodeURIComponent(href.split('#')[0]).split('/')) {
    if (segment === '..') parts.pop()
    else if (segment !== '.' && segment !== '') parts.push(segment)
  }
  return parts.join('/')
}

function parseXml(text: string, type: DOMParserSupportedType): Document {
  return new DOMParser().parseFromString(text, type)
}

// Livros mandam "XHTML" que o parser XML recusa; o de HTML aceita qualquer coisa.
function parseChapter(source: string): Document {
  const xml = parseXml(source, 'application/xhtml+xml')
  if (!xml.getElementsByTagName('parsererror').length) return xml
  return parseXml(source, 'text/html')
}

// Como o prepareEpub do leitor web: cada capítulo é montado num iframe fora da
// tela com o CSS do livro e o corpo forçado a 100 px; o tamanho predominante do
// texto dá o fator que traz a letra do livro de volta ao tamanho do tema.
export async function measureFontScale(buffer: ArrayBuffer): Promise<number> {
  const zip = await JSZip.loadAsync(buffer)
  const container = await zip.file('META-INF/container.xml')?.async('string')
  const opfPath =
    container &&
    parseXml(container, 'application/xml').getElementsByTagNameNS('*', 'rootfile')[0]?.getAttribute('full-path')
  const opfText = opfPath ? await zip.file(opfPath)?.async('string') : undefined
  if (!opfPath || !opfText) return 1
  const opf = parseXml(opfText, 'application/xml')
  const hrefById = new Map(
    Array.from(opf.getElementsByTagNameNS('*', 'item')).map((item) => [
      item.getAttribute('id'),
      item.getAttribute('href'),
    ]),
  )
  const chapters = Array.from(opf.getElementsByTagNameNS('*', 'itemref'))
    .map((ref) => hrefById.get(ref.getAttribute('idref')))
    .filter((href): href is string => Boolean(href))
    .map((href) => resolvePath(opfPath, href))

  const iframe = document.createElement('iframe')
  iframe.setAttribute('sandbox', 'allow-same-origin')
  iframe.style.cssText = 'position:fixed;left:-10000px;top:0;width:600px;height:800px;visibility:hidden'
  document.body.appendChild(iframe)
  const samples: FontSample[] = []
  try {
    const target = iframe.contentDocument!
    const view = iframe.contentWindow!
    for (const path of chapters) {
      const source = await zip.file(path)?.async('string')
      const doc = source ? parseChapter(source) : undefined
      if (!doc?.documentElement) continue
      const sheets: string[] = []
      for (const link of Array.from(doc.querySelectorAll('link'))) {
        if (!/stylesheet/i.test(link.getAttribute('rel') ?? '')) continue
        const css = await zip.file(resolvePath(path, link.getAttribute('href') ?? ''))?.async('string')
        if (css !== undefined) sheets.push(css.replace(FONT_FACE, '').replace(IMPORT, ''))
      }
      doc
        .querySelectorAll('link, script, img, image, video, audio, iframe, object, embed, source')
        .forEach((el) => el.remove())
      target.replaceChild(target.importNode(doc.documentElement, true), target.documentElement)
      for (const sheet of sheets) {
        const style = target.createElement('style')
        style.textContent = sheet
        ;(target.head ?? target.documentElement).appendChild(style)
      }
      if (!target.body) continue
      target.body.style.setProperty('font-size', `${REFERENCE_PX}px`, 'important')
      const walker = target.createTreeWalker(target.body, NodeFilter.SHOW_TEXT)
      for (let node = walker.nextNode(); node; node = walker.nextNode()) {
        const chars = node.textContent?.trim().length ?? 0
        if (!chars || !node.parentElement) continue
        samples.push({ fontSize: parseFloat(view.getComputedStyle(node.parentElement).fontSize), chars })
      }
    }
  } finally {
    iframe.remove()
  }
  return fontScaleFor(samples, REFERENCE_PX)
}

function base64ToBytes(base64: string): Uint8Array {
  const binary = atob(base64)
  const bytes = new Uint8Array(binary.length)
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i)
  return bytes
}

interface TextItem {
  str: string
  transform: number[]
  height: number
  hasEOL?: boolean
}

// Itens de texto → linhas: mesma altura na página (com tolerância) = mesma linha.
function linesOf(items: TextItem[], pageHeight: number): Line[] {
  const rows: { top: number; height: number; parts: { x: number; text: string }[] }[] = []
  for (const item of items) {
    if (!item.str) continue
    const top = pageHeight - item.transform[5]
    const height = item.height || Math.abs(item.transform[3]) || 10
    const row = rows.find((r) => Math.abs(r.top - top) <= height * LINE_TOLERANCE)
    if (row) row.parts.push({ x: item.transform[4], text: item.str })
    else rows.push({ top, height, parts: [{ x: item.transform[4], text: item.str }] })
  }
  return rows
    .sort((a, b) => a.top - b.top)
    .map((row) => ({
      top: row.top,
      height: row.height,
      text: row.parts
        .sort((a, b) => a.x - b.x)
        .map((p) => p.text)
        .join('')
        .replace(/\s+/g, ' ')
        .trim(),
    }))
    .filter((line) => line.text)
}

async function outlineOf(doc: pdfjs.PDFDocumentProxy): Promise<OutlineEntry[]> {
  const outline = await doc.getOutline().catch(() => null)
  if (!outline) return []
  const entries: OutlineEntry[] = []
  for (const item of outline) {
    try {
      const dest = typeof item.dest === 'string' ? await doc.getDestination(item.dest) : item.dest
      const ref = dest?.[0]
      if (!ref) continue
      const pageIndex = typeof ref === 'number' ? ref : await doc.getPageIndex(ref)
      entries.push({ title: item.title, pageIndex })
    } catch {
      // Destino que não resolve: o capítulo some do sumário, o texto fica.
    }
  }
  return entries
}

async function coverOf(doc: pdfjs.PDFDocumentProxy): Promise<string | null> {
  try {
    const page = await doc.getPage(1)
    const base = page.getViewport({ scale: 1 })
    const viewport = page.getViewport({ scale: COVER_WIDTH / base.width })
    const canvas = document.createElement('canvas')
    canvas.width = Math.round(viewport.width)
    canvas.height = Math.round(viewport.height)
    const context = canvas.getContext('2d')!
    context.fillStyle = '#ffffff'
    context.fillRect(0, 0, canvas.width, canvas.height)
    await page.render({ canvas, canvasContext: context, viewport }).promise
    return canvas.toDataURL('image/jpeg', 0.85).split(',')[1] ?? null
  } catch {
    return null
  }
}

async function convert(id: number, base64: string) {
  const doc = await pdfjs.getDocument({ data: base64ToBytes(base64) }).promise
  const meta = await doc.getMetadata().catch(() => null)
  const info = (meta?.info ?? {}) as { Title?: string; Author?: string }
  const pages: PageText[] = []
  for (let n = 1; n <= doc.numPages; n++) {
    const page = await doc.getPage(n)
    const viewport = page.getViewport({ scale: 1 })
    const content = await page.getTextContent()
    pages.push({ lines: linesOf(content.items as TextItem[], viewport.height) })
    page.cleanup()
    send({ type: 'progress', id, page: n, total: doc.numPages })
  }
  const result = {
    title: info.Title?.trim() || null,
    author: info.Author?.trim() || null,
    pages,
    outline: await outlineOf(doc),
    cover: await coverOf(doc),
  }
  await doc.destroy()
  send({ type: 'pdfResult', id, ...result })
}

const assembler = new Assembler()
window.__rnReceive = (chunk) => {
  const raw = assembler.push(chunk)
  if (raw === null) return
  const command = parsePdfCommand(raw)
  if (!command) return
  convert(command.id, command.base64).catch((error: unknown) =>
    send({ type: 'pdfError', id: command.id, message: error instanceof Error ? error.message : String(error) }),
  )
}

import { useImperativeHandle, useRef, type Ref } from 'react'
import { StyleSheet } from 'react-native'
import { WebView } from 'react-native-webview'
import { PDF_HTML } from '@/pdf/bundle.generated'
import { parsePdfEvent, type PdfResult } from '@/pdf/protocol'
import { chunkMessage } from '@/reader/protocol'

export interface PdfConverterHandle {
  convert(base64: string, onProgress: (page: number, total: number) => void): Promise<PdfResult>
}

interface Pending {
  resolve(result: PdfResult): void
  reject(error: Error): void
  onProgress(page: number, total: number): void
}

// WebView escondida com o pdf.js: só existe para ler PDFs na importação.
export function PdfConverter({ ref }: { ref: Ref<PdfConverterHandle> }) {
  const webview = useRef<WebView<object>>(null)
  const ready = useRef<Promise<void> | null>(null)
  const markReady = useRef<() => void>(() => {})
  const pending = useRef(new Map<number, Pending>())
  const nextId = useRef(1)

  if (!ready.current) ready.current = new Promise((resolve) => (markReady.current = resolve))

  useImperativeHandle(
    ref,
    () => ({
      async convert(base64, onProgress) {
        await ready.current
        const id = nextId.current++
        const result = new Promise<PdfResult>((resolve, reject) =>
          pending.current.set(id, { resolve, reject, onProgress }),
        )
        for (const chunk of chunkMessage(JSON.stringify({ type: 'convert', id, base64 }))) {
          webview.current?.injectJavaScript(`window.__rnReceive && window.__rnReceive(${JSON.stringify(chunk)}); true;`)
        }
        return result
      },
    }),
    [],
  )

  return (
    <WebView<object>
      ref={webview}
      source={{ html: PDF_HTML }}
      originWhitelist={['*']}
      style={styles.hidden}
      onMessage={(event) => {
        const parsed = parsePdfEvent(event.nativeEvent.data)
        if (!parsed) return
        if (parsed.type === 'ready') return markReady.current()
        const job = pending.current.get(parsed.id)
        if (!job) return
        if (parsed.type === 'progress') return job.onProgress(parsed.page, parsed.total)
        pending.current.delete(parsed.id)
        if (parsed.type === 'pdfError') job.reject(new Error(parsed.message))
        else {
          const { type: _type, id: _id, ...result } = parsed
          job.resolve(result)
        }
      }}
    />
  )
}
